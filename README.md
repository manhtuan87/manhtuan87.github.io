# ケロちゃん ランド

ケロちゃんの ゲームを えらんで あそべる メニューです。 https://manhtuan87.github.io/

- いまの ゲーム：ケロちゃん もぐもぐ（`/kero-mogumogu/`）、ケロちゃん ぴよぴよポン（`/kero-piyopiyo/`）
- Android の Chrome でこのページを開いて「ホーム画面に追加」すると、ぜんぶのゲームを1つのアプリとして遊べます
- 一度インターネットにつないで開くと、ぜんぶのゲームがオフラインでも遊べるように自動で準備されます
- 各ゲームのタイトル画面の左上にある 家のボタンで、このメニューに もどれます

## ゲームを ふやすとき

1. ゲームを別のリポジトリ（例：`manhtuan87/kero-xxx`）で作り、GitHub Pages で公開する → `https://manhtuan87.github.io/kero-xxx/`
2. `js/land.js` の `GAMES` に1行たす（名前・URL・アイコン・カードの色）
3. `sw.js` の `GAME_ICONS` にアイコンをたして、`VERSION` を上げる
4. ゲームのタイトル画面に「メニューに もどる」ボタン（`../` へ）をつける（もぐもぐ・ぴよぴよポンの `toLand()` と同じ）
5. ゲームの `sw.js` は、自分の名前で始まるキャッシュだけを消すようにする（同じサイトのゲームどうしで保存場所を共有しているため。もぐもぐ＝`kero-`、ぴよぴよポン＝`piyo-`、メニュー＝`land-`）

## PC で試す

`C:\sagyo` に各ゲームのフォルダが並んでいる状態で：

```
python tools/serve-site.py
```

http://localhost:8767/ を開くと、公開サイトと同じ形（`/` がメニュー、`/kero-mogumogu/` などがゲーム）で表示されます。

## 開発メモ

- `js/land.js` … メニュー画面（ゲーム一覧、雲の島のケロちゃん、オフラインの準備）
- `js/draw.js` … ケロちゃん ぴよぴよポンの `js/draw.js` のコピー（キャラクターの絵）
- `sw.js` … メニュー自身のファイルとゲームのアイコンだけを保存します。サイト全体（`/`）が範囲なので、それ以外の通信には手を出しません
- `offline.html` … まだ一度も開いていないゲームをオフラインで開こうとしたときの案内
- アイコンは `tools/icon.html` をゲームの絵で描き、`tools/make-icons.ps1`（ヘッドレス Chrome）で PNG にしています
