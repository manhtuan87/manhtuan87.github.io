# ケロちゃん ランド

ケロちゃんの ゲームを えらんで あそべる メニューです。 https://manhtuan87.github.io/

- いまの ゲーム：ケロちゃん もぐもぐ（`/kero-mogumogu/`）、ケロちゃん ぴよぴよポン（`/kero-piyopiyo/`）、ケロちゃん あたま ぐんぐん（`/kero-gungun/`）、ケロちゃん みるみる（`/kero-mirumiru/`）
- Android の Chrome でこのページを開いて「ホーム画面に追加」すると、ぜんぶのゲームを1つのアプリとして遊べます
- 一度インターネットにつないで開くと、ぜんぶのゲームがオフラインでも遊べるように自動で準備されます
- 更新は自動です：メニューを開いたとき・アプリに戻ったときに、メニューと 各ゲームの新しい版を探して入れ替えます（ゲームを開いている途中に届いた更新は、そのゲームのタイトル画面で自動的に読み込み直します）
- 各ゲームのタイトル画面の左上にある 家のボタンで、このメニューに もどれます
- 左上の ユーザーの ボタン（色の まると なまえ）で「だれが あそぶ？」を ひらいて、あそぶ人を えらびます。えらんだ人で ぜんぶの ゲームを あそびます
  - 4人まで。えんぴつの ボタンで 名前・こども／おとな・色を なおし、「＋ ユーザーを ふやす」で ふやします（パスワードは なし。けすときは「けす」を 2回 おす）
  - 記録は ゲームごと・ユーザーごとに 分かれます。ゲームの タイトル画面で ユーザーを かえても、メニューと ほかの ゲームも その人に なります
  - 同じサイトの `localStorage` の `kero-users` に保存（いま あそぶ人の 名前は `kero-name` にも 入れています）。一覧は `js/accounts.js`（ぜんぶの アプリで 同じ ファイル）
  - これより前の 記録：あたま ぐんぐん・みるみる の かぞくモードの ユーザーは 名前で まとめ（同じ名前は 同じ人、ゲームの 1人目は メニューの 1人目）、もぐもぐ・ぴよぴよポン の 記録は 1人目の ものに なります
- ゲームの カードの 右下と 画面の いちばん下に、スマホに 入っている 版の 番号（各 `sw.js` の `VERSION`、例：v9）が 出ます（Service Worker に たずね、まだ 入っていなければ サイトの `sw.js` を 見ます）
- 左上の 地球のボタンで ことば（日本語・Tiếng Việt・English。한국어は いったん 止めています）を えらぶと、メニューと ぜんぶのゲームが その ことばに なります（`kero-lang`。声は 日本語だけ ずんだもん、ほかの ことばは スマホの 読み上げ）。文言は各アプリの `js/lang.js`（共通）と `js/lang-text.js`（訳）
- メニューは画面全体がスクロールします（ゲームが増えても下まで見られます）

## ゲームを ふやすとき

1. ゲームを別のリポジトリ（例：`manhtuan87/kero-xxx`）で作り、GitHub Pages で公開する → `https://manhtuan87.github.io/kero-xxx/`
2. `js/land.js` の `GAMES` に1行たす（名前・URL・アイコン・カードの色）
3. `sw.js` の `GAME_ICONS` にアイコンをたして、`VERSION` を上げる
4. ゲームのタイトル画面に「メニューに もどる」ボタン（`../` へ）をつける（もぐもぐ・ぴよぴよポンの `toLand()` と同じ）
5. ゲームの `sw.js` は、自分の名前で始まるキャッシュだけを消すようにする（同じサイトのゲームどうしで保存場所を共有しているため。もぐもぐ＝`kero-`、ぴよぴよポン＝`piyo-`、あたま ぐんぐん＝`gun-`、みるみる＝`miru-`、メニュー＝`land-`）
6. ゲームの `sw.js` に、メニューが 版を たずねる メッセージへの 返事を 入れる（メニューは `GAMES` の `url` の Service Worker に たずね、まだ なければ その `sw.js` の `VERSION` を 読みます）：
   `self.addEventListener('message', function (e) { if (e.data === 'version' && e.ports && e.ports[0]) e.ports[0].postMessage(VERSION); });`
7. `js/accounts.js` を コピーして入れ（`sw.js` の `FILES` にも）、`Accounts.cur()` の 人で あそぶ。記録は ユーザーの id（`k1`、`k2`…）ごとに 分けて保存する（もぐもぐ・ぴよぴよポンの `save` と同じ）

## PC で試す

`C:\sagyo` に各ゲームのフォルダが並んでいる状態で：

```
python tools/serve-site.py
```

http://localhost:8767/ を開くと、公開サイトと同じ形（`/` がメニュー、`/kero-mogumogu/` などがゲーム）で表示されます。

## 開発メモ

- `js/land.js` … メニュー画面（ゲーム一覧、雲の島のケロちゃん、だれが あそぶ？、版の 表示、オフラインの準備）
- `js/accounts.js` … ユーザーの 一覧（だれが あそぶか）。ぜんぶの アプリで 同じ中身なので、直したら 5つの アプリ すべてに コピーする
- `js/draw.js` … ケロちゃん ぴよぴよポンの `js/draw.js` のコピー（キャラクターの絵）
- `sw.js` … メニュー自身のファイルとゲームのアイコンだけを保存します。サイト全体（`/`）が範囲なので、それ以外の通信には手を出しません
- `offline.html` … まだ一度も開いていないゲームをオフラインで開こうとしたときの案内
- アイコンは `tools/icon.html` をゲームの絵で描き、`tools/make-icons.ps1`（ヘッドレス Chrome）で PNG にしています
